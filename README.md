# Project Nemesis

Unity 6와 C#으로 만든 4인 팀 프로젝트입니다. 사이버펑크 액션 로그라이크로, 매 회차에 생성되는 방을 선택하면서 전투와 성장을 거쳐 보스에 도전합니다. PC와 모바일을 대상으로 개발했습니다.

| 조성호 담당 기능 | 구현 내용 |
| --- | --- |
| 스킬 시스템 | JSON 기반 기술 데이터, 기업별 기술팩 가중치, 조건부 콜라보 기술 |
| 플레이어 스탯 | 저장된 스탯 초기화, 공격 유형별 기초 피해 계산 |
| 서버 연동 | Firebase 로그인·자동 로그인, 클리어 기록과 강화 상태 저장 |

## 코드 샘플

- [기업별 기술팩 가중치와 콜라보 후보](01-skill-selection.md)

## Unity에서 플레이

Unity Hub의 **Add**로 [UnityDemo](UnityDemo) 폴더를 등록하고 **Unity 6000.4.8f1**에서 엽니다. Project 창에서 `Assets/Scenes/PortfolioDemo.unity`를 열고 **Play**를 누릅니다.

카드 한 장을 선택할 때마다 기업별 보유 수와 가중치가 달라집니다. 양쪽 기업 기술을 각각 세 개 이상 모으면 Fusion을 받을 수 있습니다.

포트폴리오용 기능 데모입니다. 화면 요소는 Unity 기본 도형과 GUI로 그리며, 에셋 구매나 외부 서비스 계정 없이 실행할 수 있습니다.
