# Project Nemesis

Unity 6와 C#으로 만든 4인 팀 프로젝트입니다. 사이버펑크 액션 로그라이크로, 매 회차에 생성되는 방을 선택하면서 전투와 성장을 거쳐 보스에 도전합니다. PC와 모바일을 대상으로 개발했습니다.

| 조성호 담당 기능 | 구현 내용 |
| --- | --- |
| 스킬 시스템 | JSON 기반 기술 데이터, 기업별 기술팩 가중치, 조건부 콜라보 기술 |
| 플레이어 스탯 | 저장된 스탯 초기화, 공격 유형별 기초 피해 계산 |
| 서버 연동 | Firebase 로그인·자동 로그인, 클리어 기록과 강화 상태 저장 |

## 코드 샘플
